# 更新日志

## v1.0.0

首个完整版本。

- 首页：头像 / 名字 / 介绍 / 最新文章 / 标签
- 列表页：读取 Markdown 元数据，支持标签筛选
- 详情页：单一 HTML，按 URL 中的 `id` 渲染文章
- 搜索页：Markdown 全文模糊查询，多关键词、结果高亮
- 亮 / 暗主题切换，状态持久化
- 无 `.html` 后缀的干净路由 + 静态托管重写规则
- 零第三方依赖，全量本地化

## v0.9.0

- 自研 Markdown 渲染器，支持 GFM 表格与任务列表
- 新增白名单 HTML 净化，防止 XSS

## v0.5.0

- 建立设计系统：变量化的颜色与动效
- 确定瑞士排版 + 新粗野主义的视觉方向
