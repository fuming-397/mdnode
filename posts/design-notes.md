# 设计说明

这套界面的规则很硬，也很少。规则越少，越容易保持一致。

## 视觉规则

1. **直角**：全局 `border-radius` 归零，禁止圆角、阴影、渐变与 3D 材质。
2. **纸张**：底色是带噪点纹理的浅米色，纹理由内联 SVG 生成，不产生任何外部请求。
3. **对比**：超大字号的粗体无衬线标题，与极小的正文形成强烈层级。
4. **左对齐**：所有元素严格左对齐，大量留白，用极细的黑线划分区域。
5. **强调**：只使用一种高饱和荧光绿，用作色块与选中态。

## 变量驱动

所有颜色与动画都定义在 `assets/css/variables.css` 中，组件只引用变量：

```css
:root {
  --c-bg: #f2efe6;
  --c-accent: #c8ff00;
  --dur-2: 240ms;
  --ease: cubic-bezier(0.2, 0.7, 0.2, 1);
}

[data-theme="dark"] {
  --c-bg: #0e0e0d;
  --c-ink: #f2efe6;
}
```

想换配色？只改这一个文件即可，全站同步生效。

## 主题切换

亮色与暗色主题通过 `<html data-theme>` 切换，状态保存在 `localStorage` 的**单独一个键**：`mdnode:theme`。刷新页面不会丢失，首次访问时跟随系统偏好。

## 动效

过渡时长与缓动函数同样是变量：

- `--dur-1` ~ `--dur-4`：四档时长
- `--ease` / `--ease-out` / `--ease-in`：三种缓动
- `--stagger`：列表逐个入场的延迟步长

并且尊重系统的 `prefers-reduced-motion` 设置，用户选择减少动态效果时，所有时长自动归零。

> 好的设计不是加了什么，而是决定不加什么。
